# 🎬 AutoShorts — صانع الفيديوهات القصيرة بالذكاء الاصطناعي

اكتب موضوع الفيديو، والأداة تكتب السكربت، وتجلب المقاطع المناسبة، وتضيف التعليق الصوتي والترجمة والموسيقى، ثم تُخرج الفيديو جاهزاً.
المقاسات المدعومة: **9:16** (Reels / Shorts / TikTok) و **16:9** (YouTube) و **1:1**.

## التثبيت على Windows
١. ثبّت Python 3.10 أو أحدث من python.org، وفعّل خيار «Add python.exe to PATH».
٢. ثبّت FFmpeg و Git بهذين الأمرين في نافذة cmd:
```
winget install Gyan.FFmpeg
winget install Git.Git
```
٣. نزّل الأداة إلى المجلد D:\AutoShorts:
```
git clone https://github.com/AliAlsaffarMosulUniversity/goldenMoney D:\AutoShorts
```
٤. شغّل start.bat من داخل المجلد. في أول مرة يثبّت المكتبات، ثم تفتح الواجهة في المتصفح على localhost:8501.
٥. لتحديث الأداة إلى آخر نسخة: شغّل update.bat.

مفاتيحك محفوظة في config.json على جهازك فقط، ولا تُرفع إلى غيت هب أبداً.

## الإعداد (من الشريط الجانبي)
| الإعداد | ماذا تضع | مجاني؟ |
|---|---|---|
| مزوّد الذكاء الاصطناعي | Gemini أو OpenAI أو Claude أو DeepSeek أو OpenRouter أو Groq أو Ollama أو أي خدمة متوافقة مع OpenAI، مع الـ API Key | لـ Gemini وGroq حصة مجانية، وOllama مجاني محلياً |
| مقاطع الفيديو | مفتاح **Pixabay** من pixabay.com/api/docs، أو Pexels، أو مجلد مقاطع على جهازك | ✅ |
| الصوت | **Edge TTS**، ويضم أصواتاً عربية (سعودي، عراقي، مصري، إماراتي، أردني، سوري) وإنجليزية | ✅ بدون مفتاح |
| الموسيقى | ضع ملفات MP3 في `resource\music` أو ارفعها من الواجهة | — |
| الخط | `Arial` يدعم العربية. لخط آخر ضع ملف `.ttf` في `resource\fonts` واكتب اسمه | — |

## الاستخدام
1. اكتب **موضوع الفيديو**، واختر اللغة والمقاس والصوت.
2. (اختياري) اضغط «اكتب السكربت» لمراجعته، أو اكتب سكربتك بنفسك، وضع كلمات البحث بنفس ترتيب الجمل: الكلمة الأولى للجملة الأولى وهكذا.
3. اضغط **🚀 إنشاء الفيديو**. تجد النتيجة في `storage\tasks\<التاريخ>\final.mp4`.

من سطر الأوامر:
```
python cli.py "فوائد شرب الماء صباحاً" --aspect 9:16
```

## كيف تعمل
الموضوع ← سكربت وكلمات بحث (AI) ← تعليق صوتي مع توقيت كل كلمة (Edge TTS) ← ملف ترجمة ASS ← تنزيل المقاطع (Pexels/Pixabay) ← قص وتوحيد المقاس (FFmpeg) ← دمج الصوت والموسيقى وحرق الترجمة ← `final.mp4`

| الملف | الوظيفة |
|---|---|
| `webui.py` | الواجهة (Streamlit) |
| `app/llm.py` | كتابة السكربت عبر مزوّدات الذكاء الاصطناعي |
| `app/tts.py` | التعليق الصوتي |
| `app/subtitles.py` | الترجمة المتزامنة مع الكلام |
| `app/materials.py` | جلب المقاطع |
| `app/video.py` | التركيب والإخراج عبر FFmpeg |
| `app/pipeline.py` | ربط المراحل كلها |

## حل المشاكل
- **الحروف العربية في الترجمة مقطّعة أو معكوسة:** ثبّت FFmpeg عبر winget كما في الخطوة 2.
- **خطأ Edge TTS:** تأكد من اتصال الإنترنت ومن اسم الصوت.
- **لا توجد مقاطع:** جرّب كلمات بحث إنجليزية أبسط في خانة «كلمات البحث».
